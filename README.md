# TravelDiary · 旅行日记

走过的地方，会替你发光。

一张可以旋转缩放的地球：缩小时按国家点亮，放大后按省 / 州点亮，中国可以精确到地级市。每个地方都要留下照片和一句话才会亮起来。

- 打开网址即可使用，可以「添加到主屏幕」当作 App
- 照片和文字只保存在你自己的浏览器里（IndexedDB），可在「···」里导出 / 恢复备份
- 定位、地名搜索、在地图上点选，三种方式记录地点
- 按年份查看「年度图鉴」，也可以看「此生足迹」

## 地图数据

- 国家与省 / 州边界、城市名：[Natural Earth](https://www.naturalearthdata.com/)（公有领域）
- 中国省级与地级市边界：Apache ECharts 4.9 自带地图数据（Apache-2.0）
- 国家中文名：i18n-iso-countries（MIT）

## 本地运行

任意静态服务器即可，例如 `python3 -m http.server`，然后打开 http://localhost:8000 。
